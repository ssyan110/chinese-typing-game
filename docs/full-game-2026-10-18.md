# Full eight-stop release — 2026-10-18

Student URL: https://ssyan110.github.io/chinese-typing-game/

The full route starts at Thanh Hòa village, crosses bamboo woodland, Khê Kiều harbor, a red sandstone canyon, Vân Mặc academy, a snowy pass and the ancient city, then returns home for a lantern festival. Each location has a distinct matte 3D environment and a matching static fallback. All story and interface text is Vietnamese.

The story remains a simple wrapper: introduction → visible walking → encounter → original typing battle → next location → homecoming ending. The eighth win completes the route; the map can reopen the ending. The original three opponent classes, input handling, skills, HP, timing and word-progress rules remain authoritative. No delivery, shopping or direction puzzles were added.

## Vocabulary and progress

- The eight story stops use existing chapters 1–8, with at most 20 words each and three clean presentations per word, plus defeating the opponent.
- Every supported mode, vocabulary system, level and cumulative option has enough chapters for the full journey. The smallest selected pool has nine chapters.
- Further chapters remain available after the ending and cycle through the eight landscapes. The full selected vocabulary pool remains represented; the eight-stop story is not the limit of the course.
- Previously saved word counts, chapter victories, records and backups are preserved. Old optional three-stop task-save fields remain readable for compatibility but do not drive the live story.
- A route continue button selects the first incomplete stop. A stop opens only after all prior story chapters have been won. Winning an ordinary curriculum chapter also counts toward the corresponding story stop.

## Scene and interface checks

The existing eight presentation issues from the [player audit](player-audit-2026-10-18.md) are included in this release: map art, story result names, ending blocker removal, static encounter monster, actor reset, reduced-motion fallback, accurate endless-wave wording and student-facing map instructions.

The new scenes use the same original geometry, materials, character renderer and lighting approach as the first three. Snow has a cold palette; the ancient city uses dusk lighting; the homecoming is lit by lanterns at night. Scene snapshots are generated by `scripts/render-journey-art.mjs`. No remote art runtime or additional production dependency is required.

Reduced-motion scenes render when their content changes rather than continually repainting an unchanged frame. Reduced-motion travel goes directly to the encounter. Normal walking animation remains available. The long Zhuyin progression regression checks touch input at every stop and uses the supported physical keyboard for the remaining answers; the separate player audit also completes all eight stops using touch buttons.

## Verification

`npm test` covers the real combat engine, vocabulary coverage, save compatibility and eight-stop course availability. `npm run test:browser` builds under the actual `/chinese-typing-game/` deployment prefix and plays all eight story stops in Simplified, Traditional and mobile Zhuyin, plus the maintained phone, keyboard, reward, backup, save-lock and WebKit checks.

The publication build sets `SITE_BASE` before compiling Vite, so dynamic-import preloads use the same repository prefix as the application. Browser acceptance runs this exact build-and-prepare path and treats failed scene-resource responses as failures. Rewriting root URLs after a root build alone does not update Vite's preload helper.

The separate full-vocabulary engine audit covers 84 selections and 9,011 chapter instances (including cumulative repeats), with 538,845 correct submissions. This is not a claim that each of those 9,011 chapter instances was played manually through the UI.

Independent player evidence and logs are retained locally in `output/playwright/full-release-2026-10-18/`. The production publication workflow is `Publish student game`; publication requires its build and GitHub Pages deployment jobs to succeed, followed by readback and play checks on the student URL. The release operation records the workflow URL and live check results separately.

Phone viewport automation and browser composition events do not certify a physical phone's native Chinese candidate selection. Actual classroom difficulty and learning effects remain for student/teacher acceptance.

Natural Vietnamese gate: the story follows one chronological journey, names the next place and gives a concrete action at each encounter. Copy was reviewed for meaning and ordinary Vietnamese phrasing; this is not a student-comprehension study.

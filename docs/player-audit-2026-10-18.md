## 全部词库章节的批量检查

真实 `Duel` 引擎覆盖三种输入模式、HSK／TOCFL 各七个级别、单级／累积复习，共 **84 种选择组合、9,011 个章节实例、538,845 次正确输入**。所有组合通过逐词覆盖、每词三次正确、正常奖励、正常获胜及章节完成标记检查，包含不足 20 词的末章。

9,011 是各选择组合下的章节实例，含累积复习造成的重复，**不是代理从界面逐一玩完 9,011 关**。该批测直接调用正常 `tick`、`submit`、`key` 和 `reward`，与上表的界面试玩分开记录。

## 发现并修正的问题

本轮没有发现阻断主线通关的问题。发现的八项问题集中在故事呈现、备用画面和提示一致性。

| 问题 | 复现方式与原状 | 修正 |
|---|---|---|
| 地图封面的怪物错位 | 村庄封面画灯卫，实际遇到玉卫；另两站也循环错位 | 三站封面使用纯环境图，遇敌和战斗按实际章节显示对手 |
| 故事结算跳回旧地点 | 村庄战斗标题为 Làng Thanh Hòa，结算却显示 Vườn kính | 故事结算保留当前站点名称 |
| 结尾仍有拦路怪 | 第三站获胜后进入结尾，主角仍面对战前怪物 | 结尾移除拦路怪；遇敌阶段才显示对手 |
| 无 3D 支持时看不到怪物 | 禁用 WebGL 后走到遇敌，画面只有主角 | 备用画面加入当前章节对应的怪物图片 |
| 返回后主角起点错误 | 备用画面走到终点，回地图再进村庄 | 每次进入重新设置主角起点和对手显隐 |
| 减少动画设置未覆盖备用走路图 | 游戏内勾选减少动画后，备用主角仍有跳动动画 | 备用主角也遵守游戏内减少动画设置 |
| 无尽提示和实际玩法不符 | 奖励说遇到新对手，下一波却仍是同类对手 | 提示改为下一波；说明同类对手的难度逐波增加，保留原战斗规则 |
| 地图说明写给开发者 | 原提示解释沿用旧章节和存档的实现方式 | 改为学生指令：每词正确三次并击败对手，开放下一站；进度在当前浏览器保存 |

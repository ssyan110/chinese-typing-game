# Simple journey revision — full release

The full journey is: village → bamboo woodland → harbor → red sandstone canyon → mountain academy → snowy pass → ancient city → homecoming lantern festival. Each stop has a brief introduction, walking, an encounter and the original typing battle. The eighth victory leads to a homecoming ending, which remains accessible from the map.

All player-facing story and UI text is Vietnamese. The first eight original chapters supply vocabulary, with their existing 20-word distribution, repeated practice, timer, skills, rewards and completion rules. All 84 selectable course configurations contain at least eight chapters. Chapter wins unlock the next stop. The existing save and practice records remain authoritative. Legacy story-save fields remain readable for compatibility but no longer drive gameplay.

The previously proposed delivery, direction, cargo and recall exercises have been removed from the live journey. The matte 3D scenery and character rendering remain. Walking can be skipped, leaving the map cancels travel, and a static fallback supports unavailable WebGL.

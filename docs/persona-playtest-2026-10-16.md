# 多情境玩家測試 — 2026-10-16

基準版本：259eaf3。測試在獨立 Chromium 瀏覽器與本機正式建置預覽進行，沒有使用或覆寫 Adam 的遊戲成績。這是同一個測試者模擬四種使用情境，不是真實學生使用者研究。選擇目標以可見文字、泡泡及防禦提示為準，經由 UI 點擊與鍵盤提交；遊玩階段不修改 HP、遊戲計時、分數、目標或攻擊。

## 已重現並修正

1. **同一段錯字重複扣血**：第一關填入錯字扣 4 HP，再按出招又扣 4 HP。移動目標的答題處理現在記住已判錯的草稿，未修改前不重複判錯；清空或改字後可形成新嘗試。所有五關回歸確認一次錯字只扣一次。
2. **手機 HP 擋住倒數**：魔王倒數範圍 y=401–422，怪物 HP 範圍 y=393–448，實際重疊。手機 HP 改放角色下方，角色上移保留空間；現在 HP 在 y=610–665，倒數位置維持。
3. **秒數欄位吞掉 Esc**：欄位原本停止全部鍵盤事件傳遞。現在 Esc 離開欄位並交給遊戲暫停，其他輸入仍不會變成戰鬥按鍵。
4. **高對比樣式名稱不一致**：主題使用 `high-contrast`，實際設定使用 `access-contrast`。已對齊，保留原本對比濾鏡及設定流程。

失敗證據：`output/persona-regression-before-2.log`；修正後七項檢查：`output/persona-regression-final.log`。草稿去重另有 Node 回歸測試，含重複確認、清空重輸、改成另一錯字。

## 下一個值得優先處理的產品缺口

- **手機觸控操控仍不完整**：注音依賴英文實體按鍵，F/J 防禦與 Space 絕招也沒有專用螢幕按鈕。原始碼與 UI 確認沒有觸控替代控制；因此目前不能宣稱手機不接鍵盤也能玩完所有內容。這需要設計觸控鍵盤／防禦鍵及相應戰場空間，不在這次三項 bug 的最小修正內。
- **失敗後的學習回顧較弱**：一般關卡失敗會顯示重玩／選關，但沒有成功結算那份完整詞語明細。可把錯詞回顧也放進失敗流程，讓初學者知道下一次練什麼。
